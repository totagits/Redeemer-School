# Redeemer official website photographs

The website supports an approved campus hero photograph and an eight-image school album. Keep this directory empty of identifiable children until the school confirms publication consent for each photograph.

Install the selected photos from the provided `redeemer-school-website-photo-assets.zip` into this directory with the following filenames:

- `campus-courtyard.webp` — website hero
- `campus-exterior.webp` — campus
- `classroom-learning.webp` — academics
- `classroom-activities.webp` — academics
- `students-community.webp` — student life
- `school-event.webp` — events
- `achievement-awards.webp` — recognition
- `graduation.webp` — achievements

The uploaded source images are Facebook-sized thumbnails; replace with school-authorized high-resolution originals when available. The hero has a gradient fallback if images are not installed. Do not embed expiring Facebook CDN URLs.
